# 🎶 윙윙 동물 합창단

악보를 넣으면 동글동글한 동물 주민들이 **동물의 숲 주민 같은 "동물어" 목소리**로 노래해요.
최대 **4명이 4중창**으로 각자 다른 파트를 부릅니다.

설치 없이 `index.html`을 브라우저로 열면 바로 됩니다. 목소리는 녹음된 소리 없이 Web Audio로 실시간 합성해요.

## 사용 흐름

1. **악보 올리기** — 첫 화면에서 악보 파일을 고르거나 끌어다 놓아요. 예제 악보나 텍스트 악보도 있어요.
2. **합창단 등장** — 무대에 동물 친구들이 한 명씩 통통 튀어 올라와 인사해요. 이름표에 각자 맡은 파트가 적혀 있어요.
3. **노래 시작하기** — 아래의 큰 파란 버튼을 누르면 노래를 시작해요. 가사는 무대 위에 노래방처럼 한 줄로 뜨고, 부르는 글자가 파랗게 따라가요. 다른 가사를 부르는 가수(예: 에코)만 말풍선이 떠요. 무대 아래에서 재생·처음으로·위치 이동, 합창단·소리 설정을 할 수 있어요.

화면은 토스·애플 앱처럼 회색 바탕 위 흰 카드, 큰 제목, 하단 고정 버튼으로 구성했고 다크 모드도 지원해요.

## 할 수 있는 것

- **악보 넣기**: MusicXML(`.musicxml` `.xml` `.mxl`), MIDI(`.mid` `.kar`), 텍스트 악보(`.txt`), **PDF(베타)**
  - 가사(한글·영어·일본어 가나)를 읽어서 음절대로 발음해요. 가사가 없으면 가수마다 정한 음절(기본 "라")로 불러요.
  - 화음(한 보표에 음이 여러 개)은 윗음·아랫음 파트로 자동으로 나눠요.
  - MusicXML의 코드 기호(`<harmony>`)와 박자표를 읽고, **도돌이표·1·2번 괄호·D.C.·D.S.·Coda·Fine을 펼쳐서** 불러요.
    두 번째 반복에서는 2절 가사로 불러요.
  - **PDF(베타)**: Sibelius·Finale(Opus·Helsinki·Maestro 같은 Sonata 계열 글꼴)이나 MuseScore·Dorico(SMuFL 글꼴)가 저장한 PDF에서
    음표 글자와 오선·기둥·빔의 위치로 음높이·리듬·가사·코드·빠르기를 읽어요. 총보+파트보가 합쳐진 PDF면 **파트 고르기** 화면이 나오고,
    노래 파트를 미리 골라 둬요. 스캔하거나 사진으로 찍은 악보는 읽지 못해요. pdf.js는 PDF를 올릴 때만 cdnjs에서 불러와요.
- **4중창**: 1~4명, 가수마다 파트·동물·옷 색·옥타브·**성격**(다정·발랄·새침·느긋·씩씩)·목소리(귀여움/짹짹/숨결/떨림/밝기/볼륨)를 정해요.
  음소거·솔로·목소리 미리듣기도 돼요.
- **자동 화음**: 선율 하나만 있어도 알토·테너·베이스를 만들어 4중창으로 불러요.
  - 노래 전체를 한 번에 풀어서 화성학 규칙(병행 5·8도 피하기, 성부 교차·간격, 3음·7음 챙기기, 이끎음·7음 해결, 편한 음역)을
    가장 잘 지키는 성부 진행을 골라요.
  - **화음 스타일**: 클래식(4성부 합창) / 재즈(6·7·9음을 넣은 촘촘한 화음) / 아카펠라(선율 뒤로 "우~" 화음과 "둠둠" 베이스)
  - 악보에 코드 진행이 있으면 그 코드를 그대로 따르고, 선율이 한 마디 이상 쉬는 곳에선 코드를 "우~" 하고 허밍해요.
- **재즈 편곡**: 원곡 / 스윙 / 보사노바 / 재즈 발라드 중에서 골라 들어요.
  - 노래 리듬이 바뀌어요: 스윙은 8분음표를 "따-다" 하고 튕기고, 6/8 곡을 보사노바로 고르면 셋잇단 느낌을 3+3+2(트레실로)로 바꿔요.
    박 경계는 그대로라 곡 길이와 가사 위치는 변하지 않아요.
  - 드럼·베이스·피아노(보사노바는 나일론 기타) 밴드가 악보의 코드로 반주해요: 걸어가는 베이스, 루트리스 재즈 보이싱,
    라이드 심벌·림 클릭·셰이커·브러시.
  - 자동 화음을 쓰고 있으면 재즈 화음으로 바꿔 줘요.
- **무대 꾸미기** (모두 켜고 끌 수 있어요)
  - 작은 공연 무대: 나무 무대, 커튼, 동물마다 비추는 조명, 박자에 맞춰 까딱이는 관객(끝나면 환호), 발밑 이름표
  - 배경: 맑은 낮 / 노을(반딧불이) / 밤하늘(별, 노래하는 동물에 빛) / 벚꽃(꽃잎) / 겨울 눈 / 여름 해변
  - 의상: 배경에 맞춰(벚꽃→꽃왕관, 해변→밀짚모자, 밤하늘→나비넥타이, 겨울→산타 모자) / 기본 / 꽃왕관 / 밀짚모자 / 나비넥타이 / 산타 모자 / 성가대 가운
  - 표정: 박자에 맞춰 몸이 살짝 눌렸다 늘어나고, 높은 음에선 눈이 커지고 눈썹이 올라가고, 긴 음에선 눈을 감아요
  - 반주: 피아노(기본) / 기타 / 오르골 / 없음 — 코드 진행으로 자동으로 만들어요
  - 춤: 얌전히 / 보통 / 신나게 — 노래 박자(6/8이면 점4분음표)에 맞춰 흔들어요
  - 등장할 때 동물어로 "안녕!" 인사, 끝나면 꾸벅 인사·박수·꽃가루, 낮은 목소리일수록 몸집 크게
- 가사는 무대 위에 노래방처럼 한 줄로 뜨고, **목소리·반주 소리 크기**(따로 조절, 0~150%), 빠르기·조옮김·울림(리버브), 피아노 롤(누르면 그 위치로 이동), **WAV 만들기**(반주 포함).

## 들어 있는 예제

- **Journey of dreaming** (LeeJinAh, Scored by Dayeon Kim·Echae Kang) — 올려 준 PDF의 *Main Vocal*과 *Chorus* 파트를 옮겨 적은 악보예요.
  98마디, 6/8박자, ♩=88, E♭장조 → E장조. 파트는 `메인 보컬`, `코러스`, `에코`(작은 음표로 적힌 "살아 있다는 걸", "너무 고마워" 등) 세 개이고,
  악보의 코드 진행으로 알토·테너·베이스 화음을 붙여 4중창으로 불러요.
  PDF에 들어 있는 음표 글리프 위치로 음높이·리듬을 읽고, 코드·오시아·붙임줄은 악보 그림을 보며 손으로 확인했어요.
  그래도 틀린 음이 있을 수 있으니, 원본 Sibelius 파일에서 **MusicXML로 내보내 넣는 것**이 가장 정확해요.
- 반짝반짝 작은별 (4성부), 학교 종 (선율만 → 자동 화음)

> PDF는 베타로 읽어요. 올려 주신 Journey of dreaming PDF 기준으로 코러스 111음은 모두, 메인 보컬은 두 성부로 갈라지는 2마디를 빼고 모두 맞게 읽어요.
> 가장 정확한 건 여전히 악보 프로그램에서 "MusicXML 내보내기"한 파일이에요.

## 텍스트 악보 쓰는 법

```
제목: 반짝반짝 작은별
빠르기: 96                 # 4분음표 기준 BPM

소프라노: F4 F4 C5 C5 | D5 D5 C5:2     # 음이름+옥타브[:박자], 박자 생략 = 1박
알토: C4 C4 F4:1/반 F4:1/짝            # 음표 뒤 /가사 로 한 음씩 가사를 붙일 수도 있어요
베이스: F2:1.5 R:1.5 Bb2:1/2           # R = 쉼표, 박자는 1.5 나 1/2 처럼

소프라노 가사: 반짝반짝 작은별          # 파트별 가사 (한글은 붙여 써도 한 글자씩)
가사: 반짝반짝 작은별                   # 가사 줄이 없는 모든 파트가 같이 쓰는 가사
                                       # "-" 는 앞 모음 이어 부르기(멜리스마)

박자: 6/8                               # (선택) 박자표 — 춤과 반주의 박에 써요
코드: Fmaj7:1.5 Bb:1.5 | C7:3          # 코드 진행 (박자 길이), 자동 화음과 반주가 따라가요
화음: 소프라노                          # 이 파트 선율로 알토·테너·베이스를 만들어 4중창
```

- 박자: 4분음표 = 1, 8분음표 = 0.5, 16분음표 = 0.25, 점4분음표 = 1.5
- 임시표: `C#4`, `Bb3`, `F♯5`
- 줄 맨 앞 `#` 은 주석이에요.

## 목소리는 어떻게 만드나요

`js/voice.js` — 성대 역할 발진기 하나 + 모음 포먼트 필터 3개 + 자음용 잡음으로 가수 한 명을 만들어요.

- 가사 음절을 초성·반모음·모음·받침으로 나눠(`js/phonetics.js`) 자음은 잡음/콧소리로, 모음은 포먼트 주파수로 표현해요.
- **귀여움**: 작은 동물처럼 높은 포먼트, 살짝 웃는 입 모양, 높은 배음을 줄인 둥근 음색과 약간의 숨소리(숨결),
  프레이즈 첫 음의 "짹" 하고 내려앉는 음높이와 음절마다 살짝 통통 튀는 음높이(짹짹).
- **부드러운 이어 부르기(레가토)**: 이어지는 음에서는 소리를 끄지 않고 자음 자리만 살짝 낮췄다 올리고,
  음높이는 미끄러지듯 넘어가며, 입 모양과 비브라토도 끊기지 않고 이어져요.
- 음높이·모음마다 소리 크기가 달라지지 않게 자동으로 맞추고, 높은 음에선 첫 포먼트를 끌어올려 소리가 묻히지 않게 해요.

## 알려진 한계

- PDF 읽기는 베타예요. 셋잇단음표·여러 성부가 복잡하게 얽힌 마디, 붙임줄(가사 없는 파트), 숨겨진 빈 오선이 많은 총보는 틀릴 수 있어요.
- 셋잇단음표 같은 복잡한 리듬은 MusicXML/MIDI에서는 되지만 텍스트 악보에서는 소수(예: `0.333`)로 써야 해요.
- 캐릭터와 목소리는 동물의 숲 느낌을 낸 오리지널이에요 (닌텐도 에셋을 쓰지 않아요).
